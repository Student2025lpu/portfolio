# Praveen Kondapalli — Portfolio

Responsive portfolio built with HTML, CSS and JavaScript.

## Section order
1. Home
2. About Me
3. Certifications
4. Education
5. Projects
6. Skills
7. Achievements
8. Contact

The content is based on the supplied CV. The supplied portrait is used in both the Home hero and About Me section.

Certificate URLs were not present in the CV, so direct certificate links have not been fabricated. Replace the three marked certificate anchors in `index.html` when the real URLs are available.

## Run locally
Open `index.html` with VS Code Live Server.

## GitHub Pages
Upload the project files to a GitHub repository, then use:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
